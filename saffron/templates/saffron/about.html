About SAFFRON

SAFFRON — Signal-peptide Assessment Framework For Ranking Of N-terminal edits — is a sibling tool to AMBER.

It uses SignalP 6.0 (fast mode) to predict signal peptides, designs ABE/CBE guides that introduce missense changes in the predicted SP region, and reports Δ SignalP scores for each mutant.

SignalP is run as a local CLI (Python 3.10 sidecar). When the binary is not installed, SAFFRON falls back to a deterministic mock predictor so the UI can be developed and tested.

Guide outcomes are annotated with CLIN_SIG (Ensembl VEP) and potentially pathogenic flags from Gutierrez Guarnizo et al., NAR Genom Bioinform (2023) (Supplementary File S3, sheet SupplementaryFileS3_PPVclass) when the UniProt accession and amino-acid change appear in their published catalogue. Matching “Yes” rows are highlighted in light red in the results table.

Row highlights

Guide rows in the results table can be highlighted in three ways:

  • Light red row — the amino-acid change matches a potentially pathogenic entry in Supplementary File S3 (sheet SupplementaryFileS3_PPVclass, column Potentially_pathogenic_variant = Yes).
  • Amber row tint + “SP lost” badge — SignalP predicted a signal peptide for the wild-type protein, but the mutant is predicted as OTHER (no signal peptide). Shown in the SP lost column.
  • Accent outline — the row matches an optional focus mutation you entered on the home page (e.g. A11T).
